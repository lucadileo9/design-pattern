# Analysis of papers on design patterns 

Personal notes on three academic papers studying the impact of design patterns on software quality.

## Papers analyzed:

### Paper 1 — Wedyan, Abufakher (2019)
**"Impact of design patterns on software quality: a systematic literature review"**
- Link: https://ietresearch.onlinelibrary.wiley.com/doi/10.1049/iet-sen.2018.5446
- Notes: [paper-1.md](paper-1.md)
- Type: Systematic Literature Review on 50 studies (2000–2018)
- Focus: confounding factors, quality metrics, threats to validity

### Paper 2 — Chippagiri (2025)
**"A Comprehensive Review of Software Design Patterns: Applications and Future Direction"**
- Link: https://philarchive.org/rec/CHIACR-4
- Notes: [paper-2.md](paper-2.md)
- Type: Review on 16 studies (2018–2024)
- Focus: emerging patterns (microservices, AI, cloud, security) and future directions

### Paper 3 — Elish (2025)
**"An Empirical Study on Maintainability Index of Software Design Patterns"**
- Link: https://ieeexplore.ieee.org/document/11154571
- Notes: [paper-3.md](paper-3.md)
- Type: Empirical study on 5 open-source Java systems (868 classes, 17 GoF patterns)
- Focus: Maintainability Index (MI) of patterns, comparison between categories and individual patterns
